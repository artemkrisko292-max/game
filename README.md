# ЭнергоГерой

2D-платформер про энергосбережение. Вжик, светодиодная лампочка, спасает дом от ЭнергоВампиров: собирает LED-лампочки, выключает лишний свет рубильниками и бережёт заряд.

**▶ Играть онлайн: https://artemkrisko292-max.github.io/game/**

Игра работает прямо в браузере, ничего устанавливать не нужно. Лучше всего открывать на компьютере в Chrome, Edge или Firefox. Мобильные устройства поддерживаются: есть сенсорные кнопки.

## Управление

| Действие | Клавиши |
|---|---|
| Идти влево / вправо | `←` `→` или `A` `D` |
| Прыжок | `Пробел`, `↑`, `W` или `Z` |
| Пауза | `Esc` или `P` |

На телефоне и планшете используются экранные кнопки.

## Цель игры

- Собирайте LED-лампочки, они пополняют заряд.
- Переводите рубильники: каждый выключает группу ламп и прекращает слив энергии.
- Вставьте предохранители и откройте щиток на выходе, затем пройдите в него.
- Следите за зарядом: он тает со временем, особенно под включёнными лампами. Всего в игре 20 уровней.
- Между главами показываются сюжетные сцены.

## Запуск на своём компьютере

Нужен [Bun](https://bun.sh) (или Node.js 20+ и npm).

```bash
bun install
bun run dev        # http://localhost:3000
```

Сборка статического сайта в папку `out/`:

```bash
bun run build
bun run start      # открыть собранную версию
```

## Структура проекта

```
src/
  app/                 страница и оформление (Next.js)
  components/game/     интерфейс игры, катсцены и их графика
  components/ui/       общие элементы интерфейса (shadcn/ui)
  lib/game/            игровой код:
    engine.ts            физика, правила, игровой цикл
    render.ts            отрисовка на canvas
    levels.ts            уровни
    story.ts             сюжет и тексты глав
    audio.ts, music.ts   звуки и музыка
    types.ts             типы
public/                иконки сайта
tools/                 вспомогательные проверки уровней и баланса (для разработки)
.github/workflows/     автоматическая публикация на GitHub Pages
```

## Технологии

Next.js, React, TypeScript, Tailwind CSS, Canvas 2D, Web Audio.

## Проверка уровней (для разработчиков)

```bash
bun tools/verify_levels.mjs   # все лампочки, рубильники и выход достижимы
bun tools/energy_budget.mjs   # баланс энергии по уровням
```
